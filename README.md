# PHP MySQL CRUD

A simple Employee Management CRUD application built using PHP and MySQL. This project demonstrates basic Create, Read, Update, and Delete (CRUD) operations with a Bootstrap interface.

## 🚀 Features

- Add new employees
- View all employees
- Edit employee details
- Delete employees
- MySQL database integration
- Responsive Bootstrap UI

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- Bootstrap
- MySQLi

## 📋 CRUD Operations

| Operation | Description                        |
| --------- | ---------------------------------- |
| Create    | Add a new employee                 |
| Read      | Display employee records           |
| Update    | Edit existing employee information |
| Delete    | Remove an employee record          |

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/ayushb5/php-mysql-crud.git
```

2. Move the project into your PHP server directory.

3. Create a MySQL database.

4. Create the required `employees` table.

5. Update the database credentials in `config.php`.

6. Start your PHP server.

7. Open the project in your browser.

## 📌 Purpose

This project was created to practice PHP, MySQL database connectivity, SQL queries, forms, GET/POST requests, and CRUD operations.
